# Weather card

Run bun install, bun run build, then bun run validate. Validation reviews the
generated dist package, including the bundled Vue card. The tool uses the two
reviewed Open-Meteo destinations and asks for a city.

Portable card grants are currently unqualified, so normal development admission
and installation of this package are blocked. After a browser engine passes the
contained-view gate, use the existing plugin development admission flow and
review the two destinations and card grant. Do not bypass that gate.
