# Bundled web fonts

These font files are bundled to keep production image builds
independent of external font services.

| Font | Source | License |
| --- | --- | --- |
| IBM Plex Sans | Google Fonts (v23) | SIL Open Font License 1.1 |
| Press Start 2P | Google Fonts (v16) | SIL Open Font License 1.1 |
| VT323 | Google Fonts (v18) | SIL Open Font License 1.1 |
| Caveat, weight 600, welcome-caption subset | Google Fonts (v23) | SIL Open Font License 1.1 |

The Caveat subset lives at `public/lock-page/caveat-captions.ttf`, with its license
in `public/lock-page/Caveat-OFL.txt`. It contains only the characters used by the
two welcome captions and is served locally with the lock page.
