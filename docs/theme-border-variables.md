# Theme border tokens

The current width/radius tiers and generated CSS variables are maintained in
[ThemeDefinition](../public/_documentation/themes/api-reference.md#themedefinition).
Use [theme styling](../public/_documentation/themes/styling.md) for authoring.

Use the shared variables in source controls with existing local fallbacks.
Avoid copying numeric values from a bundled theme: those values are owned by
each theme definition and may change independently.
