# Personal theme overrides

The source composable contract is maintained in
[useUserThemeOverrides](../../public/_documentation/themes/api-reference.md#useuserthemeoverrides).
For the user-facing settings flow and persistence boundaries, see
[Customize your appearance](../../public/_documentation/themes/customize.md).

Create the shared store during client setup, update it through its methods,
and use the existing background URL owner. Browser-local personal overrides,
workspace theme selection, and global accessibility preferences have distinct
persistence owners.
