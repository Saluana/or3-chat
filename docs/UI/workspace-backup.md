# Workspace backup

The maintained export/import guide is
[Back up and restore a workspace](../../public/_documentation/database/backup.md).
The [stream codec contract](../../public/_documentation/utils/workspace-backup-stream.md)
documents format validation, transaction rollback, and legacy-format boundaries.

A browser workspace backup does not restore a complete server deployment.
Cloud recovery and deployment backups are covered in
[Operate and recover Cloud](../../public/_documentation/cloud/deployment-operations.md).
