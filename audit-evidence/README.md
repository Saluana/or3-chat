# Audit evidence

Keep reusable probes and written findings here. Generated screenshots, traces,
profiles, timing captures and command transcripts belong in ignored output, not
in the source tree. Existing probes can still regenerate their output paths.

Historical captures removed during repository cleanup remain available in the
[complete audit archive at 8e855740](https://github.com/Saluana/or3-chat/tree/8e8557404d91eb6057a1d8d49faf9f7de6f34230/audit-evidence).
Report links to individual archived captures use that immutable revision.
To inspect any original file locally, use `git show 8e855740:audit-evidence/<path>`.

`planning/complete/plugin-runtime-v2/` remain versioned. Named browser harnesses
continue to retain their repeatable results under `test-results/`.
